# Experiment Command Notes

This folder stores lightweight historical command notes from earlier O256 and
DiffW-like experiments.

These files are kept for provenance and research-history reference. New students
should not start from this folder.

Recommended entry points for current StageE work:

- `../FINAL_VERSION_NOTE.md`
- `../RUN_STAGEE_FROM_SCRATCH.md`
- `../STAGEE_DEPENDENCY_MAP.md`
- `../student_handoff/README.md`

Historical commands may reference local paths, old experiment folders, or
intermediate protocols. Treat them as records of how the project evolved, not as
the final protocol.
