# Thesis Assets

Put the public thesis or paper files for the GitHub repository here.

Recommended primary thesis path:

```text
docs/thesis/thesis.pdf
```

Optional supporting files:

```text
docs/thesis/abstract_zh.md
docs/thesis/abstract_en.md
docs/thesis/bibtex.txt
```

If you later publish a paper or preprint version, you can also place it here:

```text
docs/thesis/paper.pdf
```
